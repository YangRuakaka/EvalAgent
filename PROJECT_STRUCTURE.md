# Project structure

The repository keeps executable code away from the root so that source,
experiment artifacts, and evaluation outputs are easier to distinguish.

## Dot-prefixed entries

A leading dot is the Unix convention for a hidden or tool-owned entry. Windows
does not always render it as hidden, but the meaning is the same: it is usually
configuration, cache, or internal state rather than project source.

| Entry | Purpose | Maintenance rule |
| --- | --- | --- |
| `.git/` | Git object database, refs, and repository metadata | Never edit or delete manually |
| `.gitignore` | Patterns Git should not track | Keep under version control |
| `.agents/` | Local agent instructions or task metadata | Keep unless the corresponding tooling is retired |
| `.browseruse-latest-test/` | Browser Use 0.13.6 profile/config/cache isolated from other browser runs | Regenerable; keep while running Browser Use experiments |
| `.venv-browseruse-0136/` | Python environment pinned for Browser Use 0.13.6 | Keep; recreate only when dependencies change |
| `.vscode/` | VS Code workspace settings | Keep if the team uses the settings |
| `.pytest_cache/` | Pytest's generated cache | Safe to delete; regenerated by pytest |
| `.DS_Store` | macOS Finder metadata | Not project data; ignored and safe to delete |

`__pycache__/` is also generated cache, although it has no leading dot. It is
ignored and safe to delete.

## Main directories

| Directory | Contents |
| --- | --- |
| `backend/` | EvalAgent backend and judge services |
| `frontend/` | EvalAgent frontend |
| `scripts/` | Standalone experiment, WebHarbor, analysis, data, and developer utilities |
| `technical_evaluation/` | Judge pipelines, analysis, data conversion, reports, datasets, and results |
| `browser_agent_runs_webharbor_v13_pilot/` | Canonical WebHarbor v1.3 pilot runs |
| `documentation/` | Project documentation |
| `output/` | Generated documents and other outputs |

The former `browser_agent_runs_latest_test/` contained one older laptop run
that duplicated `RET-01-A`. It was removed after confirming that the canonical
pilot run contains the same selected product plus the complete v1.3 fields.
